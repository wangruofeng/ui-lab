## Case sources

| Source | Cases | Content |
| --- | ---: | --- |
| Refactoring UI | 50 | Before-and-after interface design examples |
| The Non-Designer's Design Book | 43 | Typography and visual design examples and exercises |
| Design for Hackers | 43 | Design principles and examples |
| UI Skills Playbook | 47 | Interactive motion examples grouped by topic |
| Kill AI Slop | 35 | Before-and-after interface improvements |
| loading.dev | 36 | Loading indicators with adjustable size and speed, plus pause and replay controls |
| Transitions.dev | 44 | Motion for form feedback, content states, changing numbers, navigation, pointers, and loading |
| shadcn/ui | 17 | Component examples including date ranges, searchable multi-select, tables, charts, and attachments |
| Motion Primitives | 33 | Interactive motion examples |
| Break UI | 11 | Member profiles, lists, dates, progress, long filenames, collapsed tags, and request retries |
| Details that make interfaces feel better | 8 | Text wrapping, button padding, nested corners, icon swaps, entrances, interrupted animations, drawer exits, and background contrast |
| Stageshow | 34 | Product storytelling, linked data, collaboration, state feedback, and gestures |

The loading.dev demos use static markup and styles generated by loading-dev 0.3.8. The Transitions.dev Number pop-in and Spinning counter cases use the logic and styles of the corresponding public demos. The remaining Transitions.dev cases use plain HTML, CSS, and JavaScript and follow public references. The shadcn/ui cases use official components and example source code, with the preview scripts, styles, and fonts shipped with the site. The Break UI cases were implemented independently using the official demo and upstream edge-case data as references, and use the AI for UI site icon to identify the source. The Details that make interfaces feel better cases were implemented independently using Jakub Krehel's article as a reference and use his website icon to identify the source. Each case page links to its original reference.
